# Planning

## Portfolio view

Build it from Linear projects plus the current priority context in memory and
the global CLAUDE.md — the standing priority order lives there, not here, so it
stays current without a skill edit.

## What to optimize for

- **Independence through shipping.** Work that reaches users beats work that
  polishes.
- **Prefer compounding work** — infrastructure, automation, and reusable systems
  over one-off tasks.
- **Thomas's review throughput is the bottleneck**, not agent capacity. Batch
  decisions into one pass, and minimize how much needs his eyes at all. A plan
  that needs five approvals is worse than one that needs one.

## Staleness

Be ruthless about stale *status* — items that claim In Progress but haven't
moved, priorities that no longer match reality, trackers that drifted from what
actually shipped. Fix those directly.

But **never cancel an idea without Thomas's explicit approval.** He keeps ideas
alive deliberately (2026-08-09: "I generally want to keep all my ideas"). Flag
cancellation candidates as a question; don't act on them.
